# ATA TV — «телевизор для дедушки»

Маленький главный экран (лаунчер) для Android‑приставки. Цель — чтобы дедушка
нажимал **одну кнопку питания на пульте телевизора** и сразу попадал в FreeZona
на вкладку **«ТВ‑каналы»**, без пульта от приставки и без блужданий по меню.

```
Пульт Samsung: «Питание»
  └─ ТВ включается сразу на HDMI 3 (настройка ТВ, см. ниже)
       └─ приставка просыпается по HDMI-CEC (Anynet+)
            └─ ATA TV: заставка «Включаю телевидение…» (1,5 с)
                 └─ открывает FreeZona
                      └─ служба спецвозможностей один раз нажимает «ТВ-каналы»
```

Что бы ни случилось — перезагрузка после отключения света, кнопка «Домой»,
выход из FreeZona кнопкой «Назад» — приставка возвращается в ATA TV, а он снова
открывает FreeZona.

Готовый APK: [`dist/ata-tv-1.0.2.apk`](dist/ata-tv-1.0.2.apk) (≈46 КБ, Android 5.0+). Обновление ставится поверх предыдущей версии, настройки сохраняются.

## Установка (один раз, делает внук)

1. **Скопируйте APK на приставку** любым способом:
   - флешка → файловый менеджер приставки → открыть `ata-tv-1.0.2.apk`;
   - или по сети: `adb install -r dist/ata-tv-1.0.2.apk`.

   Если приставка спросит про «неизвестные источники» — разрешите для файлового менеджера.
2. **Откройте «ATA TV настройки»** — новый значок в списке приложений. Сверху видно
   состояние: установлена ли FreeZona, кто главный экран, включено ли автонажатие.
3. **«Сделать ATA TV главным экраном»** → выберите ATA TV → **«Всегда»**.
   Если такого экрана в прошивке нет, ATA TV откроет свойства текущего лаунчера:
   нажмите «Очистить настройки по умолчанию», потом кнопку «Домой» на пульте приставки
   и выберите ATA TV → «Всегда».
4. **«Спецвозможности»** → найдите «ATA TV: автонажатие «ТВ‑каналы»» → включите.
   На Android 13+ система может написать «Ограниченная настройка»: тогда
   Настройки → Приложения → ATA TV → ⋮ → **«Разрешить ограниченные настройки»**, и снова включите.
5. **Проверка:** нажмите «Домой» на пульте приставки → заставка → FreeZona → «ТВ‑каналы».

Плюс настройки телевизора и приставки (из исследования):

- **Samsung:** Настройки → Все настройки → Дополнительные функции → Параметры начального
  экрана → «Запуск с главного экрана Smart Hub» — **выключить** (ТВ будет включаться на HDMI 3).
- **Samsung:** Подключение (или «Общие и конфиденциальность») → Диспетчер внешних
  устройств → **Anynet+ (HDMI‑CEC) — включить**.
- **Приставка:** в настройках включить **HDMI‑CEC** (все пункты: управление, One Touch Play,
  автовыключение); заставку/«спящий режим» — по возможности «никогда».

### Если тумблер спецвозможностей сам выключается

На некоторых приставках (замечено на X96 Max с меню в стиле Android TV) после «ОК» тумблер
включается и сразу гаснет. Что смотреть:

1. «ATA TV настройки» → строки «Автонажатие (спецвозможности)» и «Служба автонажатия сейчас
   работает», а ниже — **«Журнал»**: там видно, подключалась ли служба, останавливала ли её
   система и были ли сбои. Сфотографируйте экран — по журналу понятно, в чём дело.
2. Включить службу через adb (команды ниже) и снова посмотреть журнал.

ATA TV **не включает спецвозможности сам** — это может сделать только человек
(в меню или через adb).

### Если меню на приставке урезано — через adb

```bash
adb install -r dist/ata-tv-1.0.2.apk
# главный экран (Android 7+; если команды нет — используйте меню выше)
adb shell cmd package set-home-activity kz.atatv/.LauncherActivity
# включить автонажатие (ВНИМАНИЕ: заменит список включённых служб спецвозможностей)
adb shell settings put secure enabled_accessibility_services kz.atatv/kz.atatv.TvAccessibilityService
adb shell settings put secure accessibility_enabled 1
# нужно только если ATA TV НЕ главный экран (запасной автозапуск на Android 10+)
adb shell appops set kz.atatv SYSTEM_ALERT_WINDOW allow
```

## Служебное меню

Открыть: **три нажатия «вверх»** на пульте во время заставки «Включаю телевидение…»
(подсказка «↑ ↑ ↑» в углу), либо значок «ATA TV настройки», либо кнопка
«Служебное меню» на экране ошибки.

| Пункт | Зачем |
|---|---|
| ▶ Запустить телевидение сейчас | проверить сценарий целиком |
| Режим запуска | по кругу: **«ТВ‑каналы»** (по умолчанию) → «просто FreeZona» → «канал по ID» |
| ID канала | для режима «канал по ID»: открывает `https://mobi.zona/tv/<ID>` прямо в FreeZona |
| Текст вкладки | если FreeZona переименует вкладку — впишите новый текст |
| Пакет приложения | по умолчанию `free.zona`; можно подставить другое приложение |
| Сделать главным экраном / Спецвозможности / Поверх окон | системные разрешения |
| Все приложения | любые приложения приставки, включая штатный главный экран |
| Настройки Android | системные настройки |

## Как вернуть всё как было

- Временно: Служебное меню → «Все приложения» → штатный лаунчер «(главный экран)».
- Насовсем: Настройки Android → Приложения → ATA TV → **Удалить** (или «Очистить
  настройки по умолчанию»). Приставка вернётся к своему обычному главному экрану.

## Если что-то пошло не так

| Что видно | Почему | Что делать |
|---|---|---|
| «Приложение free.zona не установлено» | FreeZona удалена или переустановлена с другим именем пакета | установить FreeZona; или поменять «Пакет приложения» |
| «Нажмите ОК, чтобы снова открыть телевидение» | FreeZona закрылась 5 раз за 30 секунд (защита от зацикливания) | нажать ОК; если повторяется — FreeZona падает, обновите её |
| Открывается FreeZona, но не «ТВ‑каналы» | автонажатие выключено, или FreeZona открылась в плеере, или текст вкладки изменился | проверить статус в служебном меню; сверить «Текст вкладки» |
| Тумблер спецвозможностей включается и сразу гаснет | система останавливает службу (причина — в «Журнале» служебного меню) | см. раздел «Если тумблер спецвозможностей сам выключается» |
| После «Домой» открывается старый экран приставки | ATA TV не выбран главным экраном | шаг 3 установки или adb‑команда выше |
| ТВ включается, а приставка «спит» | прошивка не будит приставку по CEC сама | нажать «ОК» на пульте ТВ один раз (это стандартное поведение Android) |

## Как это устроено

| Файл | Роль |
|---|---|
| `LauncherActivity` | главный экран: заставка, запуск FreeZona, защита от зацикливания, вход в служебное меню |
| `TvAccessibilityService` | после запуска до 20 с ищет надпись «ТВ‑каналы» только в FreeZona и нажимает её один раз |
| `ServiceMenuActivity`, `AppsActivity` | служебное меню (состояние, журнал) и список всех приложений |
| `DiagLog`, `AtaApp` | журнал событий и сбоев для диагностики без компьютера |
| `BootReceiver` | запасной автозапуск после загрузки, если ATA TV ещё не главный экран |
| `LabelMatcher`, `LaunchThrottle`, `AutoClickArm`, `DeepLinks`, `LaunchMode`, `LogRing` | чистая логика, покрыта юнит‑тестами |

Факты о FreeZona 3.0.75 (APK SHA‑256 `e88374c7…64f5d6`), на которых держится приложение:

- пакет `free.zona`, главный экран `ru.zona.app.android.MainActivity` (Jetpack Compose);
- своего автозапуска и выбора стартового раздела в FreeZona **нет** (нет ни одной такой строки);
- `MainActivity` разбирает ссылки `https://mobi.zona/<тип>/<id>`, тип `tv` открывает плеер
  канала; путь `/tv` не объявлен в её intent‑filter, поэтому ATA TV шлёт ссылку явным интентом.

## Сборка из исходников

Нужны JDK 17+ и Android SDK (platform 35).

```bash
./gradlew :app:test :app:lintRelease   # тесты и проверки
./gradlew :app:exportReleaseApk        # подписанный APK → dist/ata-tv-<версия>.apk
```

GitHub Actions (`.github/workflows/build.yml`) делает то же на каждый push и
прикладывает APK к сборке.

**Подпись.** Ключ `signing/ata-tv.p12` (пароль `atatv-public`) лежит в репозитории
намеренно: приложение ставится вручную, и одинаковая подпись нужна, чтобы обновления
ставились поверх старой версии. Ключ ничего не защищает и не подходит для Google Play.

Значок и баннер рисует `tools/make_icons.py` (Pillow).
